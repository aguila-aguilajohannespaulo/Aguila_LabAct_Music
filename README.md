# Introduction
Welcome to the Query Search Wiki For Music!
How it works is User -> Startup Page -> Search Page -> app.js -> Netlify Function -> Genius API -> Search Results
## Prerequisites
Before running or using the project:
1. Create a Genius API account/application and obtain a **Client Access Token**.
2. Do **not** commit the Client Access Token or Client Secret to GitHub.
3. The Genius API token should be stored as a **Netlify environment variable**.
4. If submitting the repository through GitHub, make sure your repository does not contain `.env`, API tokens, or other private credentials.
5. Set up SSH for GitHub if you have not already done so, using the earlier Git and GitHub SSH setup assignment as a reference.
6. Push the repository using **SSH rather than HTTPS**.
